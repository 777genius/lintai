# lintai `v0.1.1`

Patch release focused on scan noise reduction and clearer security messaging.

## Install

Recommended install path:

```bash
curl -fsSL https://github.com/777genius/lintai/releases/latest/download/lintai-installer.sh | sh
"$HOME/.local/bin/lintai" scan .
```

Optional npm / npx path:

```bash
npx lintai-cli scan .
```

The npm package remains a thin wrapper over the same GitHub Release assets. It downloads the matching native archive, verifies `SHA256SUMS`, caches the binary, and forwards arguments to `lintai`.

## Changes

- Reduced broad local scan noise by not descending into nested Git repositories or Git worktrees during directory walks.
- Kept direct scans of nested repositories and worktrees working, so targeted audits still behave as expected.
- Added a repo-local `lintai.toml` exclusion for the project's own malicious test corpus.
- Reworded `SEC329` and `SEC340` so findings explain the practical risk: dynamic package launch can run changed external code without a repository diff.
- Updated generated rule docs, catalog metadata, and landing content for the clearer wording.

## Compatibility

This release keeps the `v0.1` CLI and output contract unchanged. The change is intended to reduce false noise in broad parent-directory scans while preserving direct repository scans.
