# lintai `v0.1.2`

Agent Plugins integration release.

## Changes

- Recognize the published Agent Plugins 1.0 root `plugin.json` without treating unrelated files with the same name as plugin packages.
- Scan fixed Agent Plugins 1.0 `mcp.json` and `skills/*/SKILL.md` components through the existing security providers.
- Add `lintai scan-agent-plugin <package-dir>`, a versioned JSON integration surface with a fixed policy that cannot be weakened by package-controlled configuration.
- Add `lintai version` for installer and registry identity checks.
- Extend release assets to the six operating-system and architecture pairs supported by Universal Agent Plugins.

## Security contract

`scan-agent-plugin` runs the `recommended`, `preview`, `threat-review`, `supply-chain`, and `advisory` lanes. Results describe automated checks against a specific package revision. They are not a certification or a guarantee of safety.
