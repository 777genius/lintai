# lintai `v0.1.3`

Agent Plugins scan precision release.

## Changes

- Treat ordinary repo-local `../` references as normal monorepo navigation instead of path traversal.
- Keep repository escapes and parent-relative access to sensitive targets such as `.env`, `.ssh`, credentials, and private keys detectable.
- Exclude negative safety guidance and abstract detector examples from `SEC102` while retaining concrete remote download-and-execute instructions.
- Advance the fixed `scan-agent-plugin` policy identity to version 2 so installers and registries cannot reuse older assessments under the revised semantics.

## Security contract

`scan-agent-plugin` still scans inert package files only. Results bind to exact package bytes and remain automated review evidence, not a certification or guarantee of safety.
